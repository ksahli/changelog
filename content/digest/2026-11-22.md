- Patch Ghostscript now: a sandbox-escape RCE (CVE-2026-125396, "Upload2Shell") can be triggered by ordinary file uploads in apps that convert PDFs and images.
- Microsoft confirmed attackers exploited an Entra Connect Health flaw to access admin emails and tenant configuration, and Rackspace Spot was breached with access to customer Kubernetes secrets.
- GPGME before 2.3.0 has a critical memory bug (CVE-2026-129975) triggered by malicious OpenPGP keys, and MONAI Label 0.8.5 and earlier has a zero-day path traversal that AI agents found and exploited.
- OpenRouter dropped three inference providers after Dragos found months of prompt theft, including requests flagged as Zero Data Retention.
- C++26 has been finalized again, Grafana 13.3 shipped shared variables and Notebooks, and AWS Lambda now runs GPU inference.
