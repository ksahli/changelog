- PHP shipped 8.5.13, 8.4.28, 8.3.37 and 8.2.36 fixing 18 flaws, including critical RCEs such as phpAfterShell (CVE-2026-126714) and CVE-2026-115560; patch PHP today.
- Critical patches also landed for NGINX ('nginx2root'), VMware vCenter (CVSS 9.8 auth bypass), Drupal core, Ruby's Regexp/String code (RCE PoCs exist) and Java ('Java4Shell').
- CISA added exploited flaws in Synology DSM, BerriAI LiteLLM, Apache Axis and REDCap to its KEV catalog.
- PostgreSQL 19 and PHP 8.6.0 were released, and ASP.NET Core in .NET 11 adds OpenAPI 3.2 by default and Zstandard compression on by default.
- AWS Lambda now allows 30-minute timeouts for on-demand Event Functions, and Route 53 adds health checks for private endpoints.
