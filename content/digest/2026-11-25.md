- Check Point security management servers are under an active intrusion campaign with 22 organizations compromised — audit and patch Check Point management infrastructure now.
- Broadcom patched 23 VMware flaws including CVE-2026-123903, a CVSS 9.8 vCenter vmdir auth bypass, following recent zero-day exploitation of vCenter.
- CISA added Drupal Core RCE (CVE-2026-132165), N-able MailAssure SSRF (CVE-2026-134624) and MONAI Label flaws, among others, to KEV.
- Multiple cloud/supply-chain breaches: Rackspace Spot (K8s clusters and secrets accessed), Radware Cloud WAF (customer cloud keys exposed), Hex.pm, and Azure API Management secrets targeting in Norway.
- Unauthenticated SQL injection in WHMCS exposes customer data and admin hashes — hosting providers should update immediately.
