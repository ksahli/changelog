- An AI-assisted campaign has compromised 24 Check Point Security Management servers at 22 organizations; audit any internet-exposed management servers now.
- Broadcom patched 23 VMware flaws, including a CVSS 9.8 vCenter vmdir auth bypass (CVE-2026-123903), shortly after a separate vCenter zero-day was exploited.
- CISA added actively exploited Drupal Core RCE (CVE-2026-132165) and two other bugs to KEV, and Microsoft fixed an Azure API Management Classic flaw that an attacker used to hunt for secrets.
- Supply-chain incidents hit Hex.pm and six backdoored WP Connect WordPress plugins, and Rackspace is shutting down Spot after attackers reached customer Kubernetes clusters and secrets.
- Rust 1.100 stabilizes the never type and core allocator API, and AWS Lambda's maximum timeout doubles to 30 minutes for all functions with no opt-in.
